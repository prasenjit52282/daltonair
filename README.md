# Env-Health Platform Landing Page

Welcome to the official repository for the **Env-Health** website. This is an ultra-premium, highly responsive landing page optimized for showcasing open-source environmental and biosensing hardware across mobile, tablet, and laptop screens. 

It features an advanced **3D hardware explosion engine** powered by **Three.js** and scroll-linked layout animations handled by **GSAP (GreenSock Animation Platform)**.

---

## 🚀 Key Features Built-In

* **Frosted Glass Navigation:** A sticky header that begins transparent over the hero imagery and transitions seamlessly into a white frosted-glass style upon scrolling down.
* **Kinetic 3D Hardware Anatomy:** A high-contrast WebGL studio canvas that pulls apart structural components (Top/Bottom casings, Emerald PCB, Gold microprocessor, sensors) vertically as the user scrolls.
* **Mobile Hamburger Overlay:** Fluid collapse into an accessible mobile hamburger menu layer with scroll-locking to protect small-viewport alignment.
* **Zero-Dependency Local Engine:** Runs modern ES modules via CDN imports (no `npm install` or local bundlers required to preview).
